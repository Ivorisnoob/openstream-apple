# Security

## Reporting a problem

Please report security problems privately, through GitHub's **Report a vulnerability** on this repository's Security tab, rather than in a public issue. Include what you found, how to reproduce it, and what it affects. You'll get a reply as soon as possible.

## Official builds

Official builds are published only on this repository's Releases page. OpenStream is open source and builds aren't notarized, so a copy from anywhere else may have been changed; build it yourself from source if you're unsure.

## What the app does with your data

- Your library (Watchlist, progress, history) and settings stay on your Mac.
- Searches and title lookups go to TMDB; subtitle lookups go to OpenSubtitles; anime lookups go to ani.zip, AniList and AniSkip.
- Streams are requested from the sources you have turned on. Web-player sources are loaded in a private, hidden browser view that keeps no cookies or data between searches.
